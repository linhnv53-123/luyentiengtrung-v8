NÂNG CẤP V8 — BẢNG PINYIN VÀ SỔ TAY

Các file cần ghi đè/thêm:
- index.html
- css/app.css
- js/app.js
- js/study-reference.js (file mới)
- sw.js
- manifest.webmanifest

Sau khi sao chép vào repository:
1. Commit: Nâng cấp V8 bảng Pinyin và sổ tay
2. Push origin
3. Chờ GitHub Pages triển khai xong
4. Mở website với ?v=8 ở cuối URL trong lần đầu

Dữ liệu mới:
- Mô tả cách đọc Pinyin: tự lưu trên trình duyệt hiện tại
- Sổ tay: tự lưu trên trình duyệt hiện tại
- Dùng Xuất sổ tay JSON để sao lưu/chuyển thiết bị

Không cần thay đổi workflow thêm bài học.
