NÂNG CẤP V10 — SỔ TAY ƯU TIÊN DANH SÁCH VÀ NHÓM PINYIN RÕ HƠN

Thay đổi giao diện:
- Danh sách ghi chú và ô tìm kiếm được đưa lên đầu tab Sổ tay trên cả điện thoại và máy tính.
- Biểu mẫu thêm/sửa ghi chú được thu gọn trong mục “Thêm hoặc chỉnh sửa ghi chú”.
- Sao lưu JSON và đồng bộ GitHub được thu gọn trong mục “Sao lưu và đồng bộ” ở cuối trang.
- Bấm “+ Ghi chú mới” hoặc “Sửa” sẽ tự mở biểu mẫu; sau khi lưu, hủy hoặc xóa, biểu mẫu tự đóng và quay lại danh sách.
- Mỗi nhóm thanh mẫu/vận mẫu hiển thị danh sách âm ngay dưới tiêu đề, ví dụ “(b, p, m, f)”.

Cập nhật GitHub Pages:
1. Sao chép toàn bộ nội dung gói patch vào thư mục gốc repository website.
2. Ghi đè các file trùng tên.
3. Commit và Push.
4. Chờ pages build and deployment có dấu xanh.
5. Mở website một lần với ?v=10 để lấy cache mới.

Bản này giữ nguyên cơ chế đồng bộ sổ tay GitHub của V9 và cơ chế tự thêm bài học.
