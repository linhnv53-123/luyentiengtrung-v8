# Thư mục bài học

Mỗi bài là **một file riêng**. Ví dụ:

- `B13.json`
- `B14.json`
- hoặc `B14.txt`

Sau khi bạn commit một file mới, GitHub Actions tự cập nhật dữ liệu tổng hợp. Không sửa thủ công `data/lessons.json` hay `data/default-data.js`.

Xem mẫu `_MAU-BAI-MOI.txt` hoặc README ở thư mục gốc.
